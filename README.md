# Duplicate-Image-Detector

A simple C programming project that finds duplicate images in a folder and allows users to delete them.

## Features
- Scans a selected folder for images.
- Supports JPG, JPEG, PNG, BMP, and TGA formats.
- Compares image dimensions.
- Compares image pixels to find duplicates.
- Allows users to preview duplicate images.
- Gives users the option to delete duplicate images.

## Technologies Used
- C Programming
- Windows API
- stb_image Library

## Requirements
- Windows OS
- C Compiler (GCC or Visual Studio)
- `stb_image.h` header file
